Exactly Session 2. A sequence becomes an embedding matrix (rows = residues, columns = features); you pool it to one vector and score a pair with a dot product. The only new part: the encoder is pretrained on millions of sequences, so the features are learned — not the one-hot bases of a PWM. Same machine, learned coordinates — this is how an antibody–antigen SFM reaches strong retrieval from only ~4,000 pairs.
