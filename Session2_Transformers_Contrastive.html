Today's Goal

Derive the transformer attention equation — and the SFM training objective — from first principles
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
  • $QK^\top$ → matrix multiplication (all pairwise dot products)
  • $\sqrt{d_k}$ → temperature scaling
  • softmax → score-to-probability conversion
  • $V$ → information aggregation
  • Then: how two encoders learn binding — the InfoNCE loss

A Neural Network Is a Function

From Session 1: a giant parameterized function trained to fit data
$$\mathbf{y} = \sigma(W\mathbf{x} + \mathbf{b})$$
  • Linear transformation $W\mathbf{x}+\mathbf{b}$, then a nonlinearity $\sigma$
  • Stack layers → depth → hierarchical features
  • The nonlinearity is essential — without it, stacked layers collapse to one linear map
  • Preview: sigmoid fails the IIA axiom, ReLU fails unrestricted domain — only $\exp$ survives (Session 4)

From Neurons to Transformers

A 70-year arc, compressed
  • 1943 — McCulloch & Pitts: the formal neuron
  • 1958 — Rosenblatt: the perceptron (learnable)
  • 1986 — Rumelhart, Hinton & Williams: backpropagation
  • 1997 — Hochreiter & Schmidhuber: the LSTM
  • 2017 — Vaswani et al.: the transformer — attention replaces recurrence

The Sequence Problem

Text, DNA, protein, RNA — ordered sequences where meaning depends on neighbours
  • RNNs process one token at a time, carrying a hidden state $h_t = \sigma(W_h h_{t-1} + W_x x_t + b)$
  • Problem 1 — vanishing gradients: can't learn long-range dependencies (LSTMs only partly fix this)
  • Problem 2 — no parallelism: a 1000-token sequence = 1000 sequential steps
  • We need direct access to every position, computed in parallel

The Attention Idea

Bahdanau et al. 2015 → Vaswani et al. 2017
  • Don't compress the input into one vector — let each position look at all others
  • Compute a relevance score with every position, weight by relevance, sum
  • The transformer move: remove recurrence entirely; every token attends to every token, in parallel
  • Consequences: full GPU parallelization · no degradation over distance · predictable scaling → the foundation-model era

The Three Questions — Q, K, V

Three learned vectors per token
  • Query (Q): "What am I looking for?"
  • Key (K): "What do I offer?"
  • Value (V): "What information do I carry?"
  • Attention score between tokens $i$ and $j$: how well does $\mathbf{q}_i$ match $\mathbf{k}_j$?
  • $Q = XW_Q,\;\; K = XW_K,\;\; V = XW_V$  (learned linear projections)

The Attention Equation — Three Stages

Each stage is one operation from Session 1
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
  • Stage 1 — $QK^\top$: all pairwise compatibility scores (matrix multiplication)
  • Stage 2 — softmax$(\cdot/\sqrt{d_k})$: scores → probabilities (temperature softmax)
  • Stage 3 — $\times V$: aggregate information weighted by attention (weighted sum)

Multi-Head Attention

$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\ldots,\text{head}_H)\,W_O$
  • $H$ parallel heads, each with independent projections ($d_k = d_{\text{model}}/H$)
  • Different heads attend to different relationships
  • Molecular correspondence:
    • 6 CDR loops of an antibody → attention heads
    • Each loop contacts a different epitope region → each head attends to different positions
    • Combined paratope = concatenated head outputs

Self-Attention vs. Cross-Attention

Within a sequence vs. between two sequences
  • Self-attention: Q, K, V from the same sequence — how does residue 5 relate to residue 42 in the same protein? (used in each encoder)
  • Cross-attention: Q from one sequence; K, V from another — how does the antibody relate to the antigen? (used in the decoder)
  • In SFMs, cross-attention is the convergence equation at the residue-contact level

Attention Is the Convergence Equation

The identity that motivates the whole course
Transformer attention · Vaswani 2017
$$A_j = \frac{\exp(\mathbf{q}\cdot\mathbf{k}_j/\sqrt{d_k})}{\sum_k \exp(\mathbf{q}\cdot\mathbf{k}_k/\sqrt{d_k})}$$
Boltzmann binding · 1877
$$P(\text{bind }j) = \frac{\exp(-\Delta G_j/k_BT)}{\sum_k \exp(-\Delta G_k/k_BT)}$$

$\mathbf{q}\cdot\mathbf{k}_j \leftrightarrow -\Delta G_j$  and  $\sqrt{d_k} \leftrightarrow k_BT$.  Vaswani designed this for engineering. The physics requires it. (proof: Session 4)

The Encoder — What SFMs Use

Dual encoders for agent and target
  • Each encoder is a transformer producing contextual embeddings via self-attention
  • Antibody encoder → embedding $\mathbf{q}$;   antigen encoder → embedding $\mathbf{k}$
  • Compatibility score: $\mathbf{q}\cdot\mathbf{k}$ (dot product of pooled outputs)

Language Models & Contrastive Learning

The Language-Modeling Idea

A model that can fill the blank must understand the language
  • "The antibody [MASK] the antigen" → binds
  • Self-supervised: the sequence provides its own labels — no human annotation
  • Billions of sentences (or millions of protein sequences) freely available
  • The same idea, a different alphabet → protein language models

Two Ways to Learn from Sequence

Masked vs. autoregressive
  • BERT (Devlin 2019) — mask 15% of tokens, predict them from both sides. Bidirectional, contextual. → the encoder recipe.
  • GPT (Radford 2018) — predict the next token from the left only. Generative. → the SFM decoder recipe (Session 4 / Lecture 7).
  • Both: pre-train on a huge corpus, then adapt to a small task

From Words to Amino Acids

The same method, a 20-letter alphabet
  • Words in similar contexts → similar meanings
  • Amino acids in similar structural contexts → similar biochemical roles
  • Grammar constrains word order → physics constrains residue arrangement
  • If masked modeling learns language from text, it should learn biochemistry from protein sequences

Protein Language Models — The SFM Encoders

Learned structure and function, from sequence alone
  • ESM-2 (Lin 2023) — masked modeling on hundreds of millions of proteins; attention heads recover residue–residue contacts; atomic structure from a single sequence. → the antigen / protein encoder
  • AntiBERTy (Ruffolo 2022) — ~558M antibody sequences; specialized for framework + hypervariable CDR loops. → the antibody encoder
  • These are the pretrained encoders you download to build an SFM

What Language Models Don't Give Us

Powerful encoders — but they don't know about binding
  • They encode sequence → structure → function within one molecule
  • They do not encode which molecules bind which other molecules
  • To learn binding we need contrastive learning between two encoders

CLIP — Contrastive Learning

Radford et al. 2021 — two encoders, one shared space
  • Image encoder + text encoder → embeddings; similarity = dot product after L2 normalization
  • Trained on 400M image–text pairs
  • Objective: matching pairs → high similarity; non-matching → low
  • The architectural template for SFMs — but designed empirically

The N×N Similarity Matrix

The data structure at the heart of contrastive learning
  • A mini-batch of $N$ pairs → encode all → similarity matrix $S_{ij} = \text{sim}(\mathbf{z}_i,\mathbf{z}_j)/\tau$
  • Diagonal ($i=j$): correct pairs → should be large
  • Off-diagonal ($i\neq j$): in-batch negatives → should be small
  • Goal: maximize the diagonal, minimize the rest

From CLIP to CALM

Same architecture, different modalities — and 100,000× less data
  • CLIP: image + text encoders, 400,000,000 pairs
  • CALM: AntiBERTy + ESM-2, ~4,000 pairs
  • Identical recipe: dual encoders · dot-product similarity · symmetric InfoNCE · learned $\tau$
  • The difference: CLIP was designed empirically; CALM is prescribed by physics
  • ~100,000× data efficiency at comparable performance — the Level 3 signature

CALM Architecture & Results

Lee et al. 2026 — the first SFM
  • Antibody encoder (AntiBERTy) → $\mathbf{q}$;   antigen encoder (ESM-2) → $\mathbf{k}$
  • Score $s = \mathbf{q}\cdot\mathbf{k}/\tau$; trained with symmetric InfoNCE on ~4,000 SAbDab pairs
  • Held-out (80% antigen-identity clustering): R@1 6.5% / 5.4%, R@10 17% / 16%  (random ≈ 0.2%)
  • This is the reference implementation you'll fine-tune for your own data

Hard Negatives

Not all negatives are equally informative
  • Easy negative: shares no features → trivially rejected
  • Hard negative: shares partial features → forces fine-grained discrimination (similar shape, wrong charge)
  • Biological precedent: thymic negative selection presents self-antigens as hard negatives
  • Designing hard negatives is a key domain-expert decision when you build your SFM

What the Model Learns

The embedding space becomes a binding-energy landscape
  • Before: general-purpose embeddings (sequence, structure, function)
  • After contrastive training: binding partners are close, non-partners far
  • $\mathbf{q}\cdot\mathbf{k} \propto -\Delta G$ — the geometry is the physics
  • Why ~4,000 pairs suffice: ESM-2 already encodes structure; training just aligns two pre-existing spaces; the architecture guarantees the correct functional form
