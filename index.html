Final project — build your own SFM

After Session 4, each of you builds your own Specificity Foundation Model on your own data, using Claude Code with the mrc-sfm-template as the starting scaffold. The finished project is a citable research artifact — comparable to dtSFM or GenLoop. See the syllabus for the full setup.

Compute

For the final project you will need a GPU. The course supports two paths — pick whichever you have access to. Both can comfortably train at CALM scale (a few thousand pairs).

ETH students
Euler (ETH cluster)
Free GPU access via your nethz account. Request Euler access through ETH IT if you haven't already. We will help you set up the environment when the final project starts.
BIIE & non-ETH
Google Colab
Free T4 GPU notebooks at colab.research.google.com. The template will come with a Colab-ready notebook. Pro tier (~$10/mo) is useful for longer runs but not required.

If you have access to other compute (a lab GPU workstation, an HPC allocation elsewhere), it works too — the template is portable. Detailed setup notes ship with the template.

Anyone in the lab can take this course. The math is at the level of college algebra and basic calculus. You do not need to know how to code — that is what Claude Code is for. The only thing you need is your own domain expertise and your own data.
