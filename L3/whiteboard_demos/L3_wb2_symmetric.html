The Symmetric Loss

MRC LECTURE 3 · WHITEBOARD · BIDIRECTIONAL TRAINING FROM BINDING SYMMETRY
Claim
$$\mathcal{L}_{\text{sym}} = \tfrac{1}{2}\big(\mathcal{L}_{\text{agent}\to\text{target}} + \mathcal{L}_{\text{target}\to\text{agent}}\big)$$
InfoNCE applied to the rows of the similarity matrix asks "for each agent, which target?" But binding is symmetric — the free energy of a complex doesn't care which partner you call the agent. The loss must reflect that. We add the column-wise direction and average.
Step 1 · Agent → target (softmax over each row)
$$\mathcal{L}_{\text{agent}\to\text{target}} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(S_{ii})}{\sum_{j=1}^{N}\exp(S_{ij})}$$
Step 2 · Target → agent (softmax over each column)
$$\mathcal{L}_{\text{target}\to\text{agent}} = -\frac{1}{N}\sum_{j=1}^{N}\log\frac{\exp(S_{jj})}{\sum_{i=1}^{N}\exp(S_{ij})}$$
Step 3 · The physical constraint
$$\Delta G_{AB} = \Delta G_{BA} \;\;\Rightarrow\;\; \text{sim}(\mathbf{q}_A,\mathbf{k}_B) = \text{sim}(\mathbf{q}_B,\mathbf{k}_A)$$
Step 4 · Average both directions  ∎
$$\mathcal{L}_{\text{sym}} = \tfrac{1}{2}\big(\mathcal{L}_{\text{agent}\to\text{target}} + \mathcal{L}_{\text{target}\to\text{agent}}\big)$$
