Scaled Dot-Product Attention, Computed

MRC LECTURE 2 · WHITEBOARD + MATRIX · THE ALGEBRA ON THE LEFT, ONE TOKEN'S PATH ON THE RIGHT
Goal — build this equation
$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$
Source · Q, K, V are three learned views of the same embedding
$\mathbf{q}_i = W_Q\mathbf{x}_i,\;\; \mathbf{k}_i = W_K\mathbf{x}_i,\;\; \mathbf{v}_i = W_V\mathbf{x}_i$
$\mathbf{x}_i$ = token $i$'s embedding (from the pretrained PLM/LLM); $W_Q,W_K,W_V$ are learned during training
Stage 1 · all pairwise scores (matrix multiply)
$S = QK^\top,\quad S_{ij} = \mathbf{q}_i\cdot\mathbf{k}_j$
row $i$ of $S$ = token $i$'s score against every key
Stage 2a · scale by √dₖ (the temperature)
$\tilde{S} = \dfrac{QK^\top}{\sqrt{d_k}}$
keeps softmax in its sensitive range — same $\tau$ as $k_BT$
Stage 2b · softmax each row → weights  (the convergence equation)
$A_{ij} = \dfrac{e^{\tilde S_{ij}}}{\sum_k e^{\tilde S_{ik}}}$
a probability distribution (sums to 1) — and the same form as Boltzmann $e^{-E/k_BT}/Z$
Stage 3 · aggregate values (weighted sum)
$\mathbf{o}_i = \sum_{j} A_{ij}\,\mathbf{v}_j$
the output is a blend of value vectors, weighted by attention
Assemble the three stages  ∎
$\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$
