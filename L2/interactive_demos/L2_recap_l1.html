Recap — The Four Tools from Session 1

LECTURE 2 · EVERYTHING TODAY IS BUILT FROM THESE
Before we build attention, get back in the frame: a molecule is a vector, recognition is a score, and a score becomes a probability. Four operations do all of it.
Attention is nothing but these four, stacked: matrix-multiply to score every pair, scale, softmax to choose, then blend. Today we assemble them.
