One neuron: multiply each input by a learned weight, add them up with a bias, pass through a nonlinearity. Stack thousands of these and you get a transformer. Without σ, stacking neurons collapses back to a single linear map — the nonlinearity is what makes depth worth anything. (Which nonlinearity?
