Each token builds a query and compares it — by dot product — against every token's key. Softmax turns those scores into attention weights. Lower the temperature and attention sharpens onto the single best match; raise it and attention spreads out. This is the same softmax-over-scores you saw in Lecture 1 — and the Boltzmann distribution in Lecture 4.
