Proof — $S = QK^\top$ is the Pairwise Similarity Matrix

MRC LECTURE 1 · WHITEBOARD 2 · STEP-BY-STEP DERIVATION
Claim to prove
$$S_{ij} = \mathbf{q}_i \cdot \mathbf{k}_j \quad\text{for all } i, j$$
Let $\mathbf{Q} \in \mathbb{R}^{m \times d}$ be a matrix of agent embeddings (row $i$ is agent $i$'s embedding $\mathbf{q}_i$). Let $\mathbf{K} \in \mathbb{R}^{n \times d}$ be a matrix of target embeddings (row $j$ is target $j$'s embedding $\mathbf{k}_j$). We will show that one matrix product $S = QK^\top$ produces an $m \times n$ matrix whose entry $(i, j)$ is the dot product of agent $i$ with target $j$.
Step 1 · Apply the definition of matrix multiplication
$$S_{ij} \;=\; \big(QK^\top\big)_{ij} \;=\; \sum_{l=1}^{d} Q_{il} \,(K^\top)_{lj} \;=\; \sum_{l=1}^{d} Q_{il}\, K_{jl}$$
Step 2 · Identify the components
$$Q_{il} = (\mathbf{q}_i)_l \quad\text{(} l\text{-th component of agent } i\text{'s embedding)}$$ $$K_{jl} = (\mathbf{k}_j)_l \quad\text{(} l\text{-th component of target } j\text{'s embedding)}$$
Step 3 · Substitute  ∎
$$S_{ij} \;=\; \sum_{l=1}^{d} (\mathbf{q}_i)_l \,(\mathbf{k}_j)_l \;=\; \mathbf{q}_i \cdot \mathbf{k}_j$$
