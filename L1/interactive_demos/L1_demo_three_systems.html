Three Systems, One Problem

MRC LECTURE 1 · SLIDE 5 · CONCEPTUAL OVERVIEW
Three biological and computational systems that look completely different at first glance — antibody recognition, transcription factor binding, and transformer attention — all face the same mathematical challenge: convert a set of compatibility scores into selection probabilities.
Antibody → Antigen
Agent (q)antibody CDR loops — surface features of the binding paratope
Target (k)antigen epitope — surface features of the target protein
score $= \mathbf{q} \cdot \mathbf{k}$
TF → DNA Site
Agent (q)transcription factor's DNA-binding domain — positional preferences for nucleotides
Target (k)candidate DNA binding site — actual nucleotide identities
score $= \mathbf{q} \cdot \mathbf{k}$
Query → Key
Agent (q)transformer query vector — what the current token is looking for
Target (k)transformer key vector — what each candidate token offers
score $= \mathbf{q} \cdot \mathbf{k}$
All three solve the same problem
Compute a score with $\mathbf{q} \cdot \mathbf{k}$, then convert all scores into a probability distribution with softmax.
Different molecules, different fields, identical math.
