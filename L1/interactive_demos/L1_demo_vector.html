A Molecule Is a Vector

MRC LECTURE 1 · INTERACTIVE DEMO · WHAT A VECTOR REALLY IS
Describe an amino acid by its physical properties — hydrophobicity, size, charge, polarity. That ordered list of numbers is a vector. Click a residue: see its property list (left) and where those numbers place it as an arrow in "property space" (right).
Each property is one coordinate. Similar residues → similar lists → arrows pointing the same way.
The property vector
Property space — the same numbers as a direction
Turning a molecule into a list of numbers turns biology into geometry. Two residues that point the same way share properties — and that "pointing the same way" is exactly what the dot product measures next.
