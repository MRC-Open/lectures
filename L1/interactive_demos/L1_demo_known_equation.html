Knowing the Equation Is a Superpower

MRC LECTURE 1 · INTRO · PARAMETER ESTIMATION IN A KNOWN EQUATION
$$y \;=\; m\,x \;+\; b$$
Here are ten data points. You don't know the slope m or the intercept b — but you do know the form: y is a straight line in x. With a known form and only ten points, you can recover both numbers, then predict y for any x (or x for any y) — forever.
Concrete instance: x = trip distance (km), y = taxi fare ($). The lesson is general — it holds for any known equation.

Two parameters. Ten points. Predict anything, forever. Standard deep learning has to learn the whole shape from millions of examples — function approximation. An SFM already knows the shape (Boltzmann = softmax); it only estimates parameters — parameter estimation. That is why CALM needed ~4,000 pairs, not CLIP's ~400,000,000. Every standard curve you run — ELISA, Bradford, qPCR — is this exact move: known linear form, a few standards, then read off unknowns.
