The Dot Product, Step by Step

MRC LECTURE 1 · INTERACTIVE DEMO · TWO LISTS OF NUMBERS → ONE NUMBER
$$\mathbf{a}\cdot\mathbf{b} \;=\; a_1 b_1 + a_2 b_2 + a_3 b_3 + a_4 b_4 \;=\; \sum_{i} a_i b_i$$
Two feature vectors — an antibody $\mathbf{a}$ and an antigen $\mathbf{b}$, each a list of four numbers. Click a feature (or "Compute all") to multiply the matching components and add them up. The single number that comes out is the compatibility score.
Two lists of numbers in, one number out. Matching features (the $3\times2$ on hydrophobicity) add compatibility; a clashing feature (the $-1\times2$) subtracts it. That one number is exactly what the next slides analyse — first algebraically, then geometrically.
